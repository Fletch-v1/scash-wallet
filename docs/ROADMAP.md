# Roadmap

MVP (phase 1)
- Wallet core: BIP39 seed, BIP32/BIP44 derivation, address generation
- Network adapters: Electrum or public API (read UTXOs, broadcast TX)
- Desktop UI: Electron + React basic send/receive
- Encrypted local storage of seed, seed backup flow

Phase 2
- Hardware wallet / PSBT support
- Coin selection improvements and fee estimation
- Tor integration and privacy improvements

Phase 3
- Mobile clients
- Multi-account and multi-currency support
